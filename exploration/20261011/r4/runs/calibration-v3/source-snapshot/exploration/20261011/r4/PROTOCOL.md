# R4预声明：匹配信息与调用机会的时序表示/执行反馈对照

仅准备，0真实模型；不执行R3/v2/v3计划。新计划SHA须后续明确放行，串行、无重试/补样/换模型，不因离线通过自动执行。

## 问题、处理因素与可识别范围

检验新时序机制中，控制调用机会与规格事实后，层次化结构契约和公开执行反馈是否减少语义错误；记录意图对规格、RTL对意图、RTL对规格三种可观察偏差。不是证明模型内部思维，不把BOTH_DIVERGE唯一归因任何阶段。

采用表示S=JSON分节契约、L=线性受控语言；同一寄存器/表达式/时钟复位语义域，两格式使用相同表达式语言、支持限制和任务信息，解析为同一个可执行合同。L仍有语法约束，主张仅限层次组织形式，不能声称相对任意自由散文的优越性。未选自由散文方案：意图偏差需额外模型转译或主观人工标注，不能在48调用内保留等阶段并排除转译影响。也未选人工正确IR方案：那只能校准机械编码，不测自然意图偏差。

每例两个真实模型意图，分别由S/L阶段1生成；各阶段2模型生成首次RTL。阶段3在同一表示内部将完全相同意图、首次RTL、规格/接口/公开例子、实现指令交给F=有执行反馈和R=无反馈重新生成。两臂区别仅新增实际公开检查JSON。R拿到当前候选而非弱化为从空白开始，保留竞争力的重新生成基线。禁止把人工正确契约、独立参考/隐藏数据给任何主臂。

表示主比较S-R对L-R与S-F对L-F，只改变表示处理及其真实模型产物；两个表示都有同样意图、首次RTL、最终RTL三阶段。反馈主比较各表示F对R共享阶段1/2，只增实际执行信息。交互以(F-R)_S-(F-R)_L描述，不从跨阶段变化推断独立因素。反馈是唯一有意信息增量，“等信息”指表示对照设计事实一致及反馈比较的非反馈上下文一致，不称四臂输入完全相同。

## 调用图及预算

三新族epoch_commit/refund_credit/tagged_join，各2重复=6例。每例：S意图+L意图=2唯一调用；S首次RTL+L首次RTL=2；S-F/S-R/L-F/L-R最终RTL=4，总8，全部48。每策略6×3=18机会；共享前两阶段每表示各12调用不能重复算成实际账。实际48=24共享+24分支；将每表示共享费用一半分摊F/R，每策略实际分摊12调用；完整独立部署视角各18机会/含全共享费用另报，不能求和作实际72调用。

相同gpt-5.6-sol/low，ephemeral禁工具，串行，180秒/调用；派发10800秒，磁盘750MiB，模型调用上限48。前4仅以生成返回/工具边界判断服务可用，不看功能成绩/格式择样；失败停止，无周期重试。任务/表示与臂先后按重复/家族固定交替，不基于成绩改变。

可执行限制：所有prompt UTF8最大256KiB，超过标INPUT_LIMIT，不调用、全分母保留；intent输出解析最大16KiB，RTL提取128KiB，超限/非法格式为功能/格式失败且保留全原文，仍给后续机会，后续prompt超输入限制也保留；stdout/stderr沿用2MiB硬捕获与壁钟清理，超限/超时为未知/基础设施结果，停止、不重发。输出响应先完整保存再判格式，不把后验长度当删样依据。CLI没有已验证的服务token上限参数，因此不能声称严格等token/等算力；字节限制不是token限制，也不是服务生成token约束。

主分析每策略固定6计划例PASS数/6，格式、unsupported、INPUT_LIMIT、工具策略失败计非PASS；API/未知/PENDING分别列出，固定分母不删样。报告所有12意图、12首次RTL及24最终RTL。反馈效果6对/表示含help/harm/no_change/inconclusive，未完成不能伪装等价。服务中断时完整已生成子集只作敏感性分析，不按效果删除。主公平性为匹配调用机会；另外报实际input/output/cache-write/cache-read/reasoning字段（缺失null不当0）、字节长度、时延和半共享/全共享费用账。按实际token的描述性效率与每族结果、仅可解析IR的条件子集均是敏感性分析，不能替代主分母或推断等token因果效果。2重复/族无可靠显著性或泛化估计。

## 意图支持域与定位

1时钟二值事件，rising/falling边沿；async_low/sync_low/none复位；1..16无符号寄存器、每个1..8位，声明合法复位值；独立组合输出，可读输入/rst_n/旧寄存器。每寄存器恰一next表达式，所有输出覆盖。并行旧状态求next，赋值按位宽截断；输出按接口截断。有限整数常量0..65535、+/-/&/|/^、单比较、and/or/not、条件表达式；表达式最大4096字符/512 AST节点，总意图16KiB。支持计数、多位状态、数据缓存、复位/优先级用条件嵌套表示。不支持多时钟、四态、带符号、数组/存储器原语、层次、动态调用/属性、循环、递归或外部文件。违规语法/重复字段/覆盖错误=IR_INVALID或EXTRACTION_ERROR；域外宽度/操作/名字引用=UNSUPPORTED。不自动修补或用正确IR替换。

寄存器复位值也是解释器初态；主检查先强制复位再释放，限于冻结二值事件。组合值每事件即时求；非边沿保持仍检查组合合理变化。人工正确契约仅calibration_contracts，不能进prompt模板、计划或真实模型分母。

意图检查是模型产物的可执行解释，对公开/隐藏过程参考各比一次。RTL_spec用固定过程参考事件；RTL_intent只在意图受支持时用同一事件但期望来自该真实意图。IR无效时RTL_intent=NOT_ASSESSABLE，不强行归因。三状态原始记录，支持INTENT_DIVERGES、RTL_DIFFERENT_INTENT、BOTH_DIVERGE等观察；即使IR错/RTL跟随，也只能定位可观察一致性，不能证明内部模型因果链。最终阶段只重新实现RTL，初始意图不重写，故可观察绕过/修正意图，不能称意图修复率。

反馈仅公开检查的IR_spec/RTL_spec/RTL_intent状态及最多8条公开事件差异，非法意图给格式诊断；不会用隐藏状态/参考RTL/人工正确契约或隐藏评分。公开失败也不能看成绩后加强例子。所有私有评分只在生成结束/停止后进行。
