# 发现

现有全端口逐拍精确判据不能直接移植为延迟宽容的流事务判据。本轮另建同作者独立开发材料，检查基于外部输入计划/实际握手/逐消费者FIFO，而非参考逐拍波形。不是外部保留集/模型自然收益/无界证明。

校准表明只屏蔽invalid payload不足：必须同时校验每consumer完整事务顺序/次数、stall保持和固定source计划的有界完成；source永远ready0要拒绝空账PASS。缺失判断依赖有限公平drain，不能推断无界丢失/无限延迟。native只一个手写implementation家族3合法/7fault参数变体，非自然模型研究；reset取消为手推语义见证而非hardware中途reset证明。独立flat账复核仍同作者，不宣称外部作者独立。默认传输回归失败保留，未诊断已确认代理根因。
