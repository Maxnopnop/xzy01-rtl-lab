# 候选方向矩阵与排序

2026-10-11。排序依据：对已有研究缺口的信息价值、可证伪性、资源可行性，而非预期正收益。所有方案都需要独立题族、共同设计事实和固定隐藏评分。E1/E2/E3均是开发探索，未建立最终集。

|优先级/方向|机制与可证伪假设|最近邻原始工作|预期错误|混杂因素|资源/实验成本/立即可执行|
|---|---|---|---|---|---|
|1 公开例子覆盖及负例校准|冻结v2，用未用于例子选择的复合编辑检验；H：覆盖不因两处编辑明显下降；等价重命名/冗余状态不得误报|AutoFSM差分检查；LLM-FSM转移覆盖；本仓库旧mutation开发拟合|补偿故障、长历史、复位、拍数|同五开发题不是真正未见题；注错分布非自然错误率|E1/E2，0模型调用，<10000图、约百次Icarus，立即执行|
|2 例子信息量×执行反馈因果分离|原/增强例子×无/有反馈；H：相同例子下反馈仍增加修复；按题报告帮助/伤害/不变|VeriRefine检查与修复；AoT结构化提示|已公开例子可发现的转移错误|v2新增事实本身作用；条件修复选择偏差；token差异|E3，5题×4格=20调用，已有通道；扩展先核实可靠性|
|3 确定性IR→RTL对照|正确/错误表均编译，记录忠实程度；H：在限定Moore域消除实现偏差却不能修复语义错误|LLM-FSM Spec→YAML→fsm2sv、AutoFSM JSON→YAML→RTL|编码、always、复位、输出组合/时序|自动转换支持域较窄；手写参考错误；正确表泄漏|E2现有fixture转换作为对照，0调用；未来同第一阶段IR分支为编译/LLM翻译|
|4 时序契约规范化/歧义识别|抽取边沿前后、复位优先级、接收/输出拍数并绑定原文；H：只重表达相同事实减少时序错|VeriRefine ASTF及citation；AoT分类IR|提前/滞后一拍、同步/异步、overlap|补足规格缺失信息不是重表达；人工标签偏见|先人工审计开发规格，后每题原文/规范化2组；20–40调用起步；不自动猜歧义答案|
|5 反例反馈与定位稳健性|最短行为见证、前后状态、错误字段作为反馈粒度；H：短见证降低token且不伤修复|AutoFSM错误trace、VeriRefine分阶段路由|深路径、输出状态混淆、错误传播|私有反例泄漏；同oracle循环自证|E1最短见证离线核对；后公开有限例子内长/短反馈、等调用；不能给模型隐藏评分反例|
|6 IR/schema表示选择|状态表与优先级guard、Moore/Mealy/计数器模式并列；H：匹配设计类别优于通用表|AoT五类结构；VeriRefine ASTF；LLM-FSM YAML|条件优先级、状态爆炸、Mealy时机|支持域/提示长度/示例不同；新schema增加工具工程|当前单bit Moore可执行，Mealy和计数guard待版本化；每家族3条件至少30调用|
|7 分解/分阶段检查|规格→IR和IR→RTL独立公开检查，与最终一次检查对照；H：早检查能减少错误传递|VeriRefine阶段审计直接先例|规格遗漏、忠实错误实现|原规格仍参与RTL阶段会纠正表；阶段标签只是可观测偏差|已有runner可执行；新独立端到端配置至少2调用/输出；不能把旧条件修复当端到端|
|8 形式/差分/变形测试|IR有限图精确检查，RTL独立oracle仿真，Yosys等价另立证据层；H：存在固定向量漏错或判题矛盾|LLM-FSM Yosys equiv；AutoFSM SystemC|长历史、不同状态编码、测试不足|复位模型及X初始化、共源参考/TB偏差、求解未证不等于正确|E1/E2立即；Yosys已在WSL，sby/外部solver不在PATH；RTL形式流需单例校准后新批次|
|9 修复与等调用重新生成|相同两次调用总上限，第二次分别局部修复/从规格重新生成；H：修复在自然错误上优于重采样|VeriRefine定向修复；AutoFSM再提取IR|锚定错误表、补丁不全|只对已失败样本条件化；第一调用token不等|尚未执行；应保留首次全部输出，配对共享初稿；至少5独立题×2分支|
|10 自检/交叉审查/候选选择|独立检查者与自述检查、公开执行检查比较；H：审查超过等调用重生成|AutoFSM Verifier/Judger；AoT多模型方案|遗漏、错误信心、关联错误|检查者看隐藏分数；多候选泄漏和best-of选择；多模型成本|无独立模型审查实测；可做20–40调用开发小批；公开选择规则冻结|
|11 预算分配/停止策略|按公开风险触发额外调用，匹配固定上限和直接生成N候选；H：单位token通过题数改善|LLM-FSM test-time scaling；VeriRefine限次修复|无效修复、简单题浪费|停止依据若隐藏评分会泄漏；API失败成本未知|先由现有usage建成本表；策略评估需新端到端样本；不重复固定输出充数|
|12 复合故障/复杂度/鲁棒性|编辑数量、可达深度、状态数分层，并测重命名/措辞变体；H：效果随复杂度下降|LLM-FSM参数化图与分层；AutoFSM SKT-FSM|长依赖、补偿/掩蔽、状态规模|人工注错概率不真实；同图变体不可当独立题|E1复合编辑立即；随机独立图需单独开发集；新复杂规格模型调用待下一批|
|13 检索与知识约束|冻结许可语料，取复位/时序规范而非近重复答案；H：规则检索比等长静态规则更有效|Lewis等RAG原论文；VeriRefine子类型规则检索式提示|工具语法、时序惯例|训练污染、答案近重复、检索改变设计信息、tokens膨胀|目前无已审核知识库；可做规则静态基线，RAG暂低优先，不重建基础设施|
|14 扩展公开题来源/最终集审计|按机制和题族选择、来源锁、许可、语义去重与独立参考审核；H：开发收益不能解释全部新题|VerilogEval、RTLLM、LLM-FSM|分布外语义/多输入/组合边界|公开题污染、人工选择容易题、适配语义变化|来源工具存在，先审计再冻结；保留题不在此轮使用；Proposal40题目标未完成|

## 原始来源复核与代码边界

- [VeriRefine v1](https://arxiv.org/html/2607.18519v1)，Xiangfei Kong、Tasnim Tabassum、Marwan Abdelwahab、Hao Zheng：ASTF、分层审计和理解/实现修复直接重合；§4.1允许最多两次后续修复并计token。不能把阶段定位称新颖。网页未给可确认作者实现链接；定向检索没有确认代码身份，因此预算/审计实现未复现。
- [LLM-FSM v1](https://arxiv.org/html/2602.07032v1)，Yuheng Wu等：NL→YAML→确定性RTL、状态/转移覆盖和Yosys equiv已有先例；状态复杂度分层可借鉴。原文/摘要未确认作者数据代码地址，不借用同名聊天FSM包。未下载集合、未核实许可、未复制为最终集。
- [AutoFSM v1](https://arxiv.org/html/2512.11398v1)，Qiuming Luo等：JSON→YAML→fsm2sv、SystemC/Verilator差分、Judger/Fixer；§5.1限制20 agent actions。action不等于模型turn，当前没有作者实现证据可换算完整调用/token。作者框架/数据代码未确认。
- [AoT v1](https://arxiv.org/html/2505.15873v1)，Matthew DeLorenzo等：分类、JSON IR、逐行伪代码；156题、每题5样本；默认最大输出token。v1采用温度0.6，文中另写top-k0.99，不自行修正为top-p。[作者Prithwish Jana页面](https://jprithwish.github.io/publications.html)确认论文身份，仅链接arXiv；未找到可核对的作者实现。v2全文未复现。
- [fsm2sv作者工具](https://github.com/mohamed/fsm2sv)：核对README与源代码，YAML转换器而非上述四篇作者实验框架。不能将第三方可用工具称为已复现AutoFSM/LLM-FSM。
- [RAG原论文](https://arxiv.org/abs/2005.11401)、[VerilogEval作者库](https://github.com/NVlabs/verilog-eval)、[RTLLM作者库](https://github.com/hkust-zhiyao/RTLLM)：候选机制/来源定位，本轮未复现训练或重新导入benchmark。

这些是有边界的原始文献核查，不是穷尽综述；代码无法确认的地方明确保留待验证，不依据二手“开源”标签认定已复现。
