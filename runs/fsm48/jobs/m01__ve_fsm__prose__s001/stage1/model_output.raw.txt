Implement `TopModule` as a four-state Moore FSM using a state register, combinational next-state logic, and combinational output decoding.

Use `reg` and `localparam` declarations to encode states A, B, C, and D. Two state bits are sufficient. The state register updates on each positive clock edge. It also has an active-high asynchronous reset: whenever `areset` is asserted, immediately set the current state to A without waiting for a clock edge. Otherwise, each rising edge loads the computed next state.

Implement the transition logic with a `case` statement based on the current state:

- In A, remain in A when `in` is 0; transition to B when `in` is 1.
- In B, transition to C when `in` is 0; remain in B when `in` is 1.
- In C, transition to A when `in` is 0; transition to D when `in` is 1.
- In D, transition to C when `in` is 0; transition to B when `in` is 1.

Provide a safe default for illegal or unknown state encodings that sends the FSM to A. Assign a default value to the next-state signal before the `case` statement so the combinational logic is fully specified and does not infer latches.

Because this is a Moore machine, derive `out` solely from the current registered state, not directly from `in`. Assert `out` only while the current state is D; drive it low in A, B, C, and any invalid state. Resetting to A therefore makes the output 0.

Output timing follows the registered state transitions. The input is sampled at each rising clock edge, the state changes according to the transition table, and `out` then reflects the newly entered state during the following clock cycle. Thus, a rising edge that moves the FSM into D causes `out` to become 1 immediately after that edge. A rising edge that moves it out of D causes `out` to return to 0. This preserves the example traces and permits overlapping input patterns naturally through the specified transitions.
