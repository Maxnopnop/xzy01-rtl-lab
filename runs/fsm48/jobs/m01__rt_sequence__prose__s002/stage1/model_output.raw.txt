Implement `sequence_detector` as a five-state Moore finite-state machine clocked on the rising edge of `clk`. Use `reg` and `localparam` declarations for the state and encodings, with separate combinational next-state/output logic and sequential state storage.

The states represent the longest prefix of `1001` matched so far:

- `IDLE`: No relevant prefix has been matched.
- `S1`: The suffix `1` has been matched.
- `S2`: The suffix `10` has been matched.
- `S3`: The suffix `100` has been matched.
- `S4`: The complete sequence `1001` has just been matched.

Use these transitions:

- From `IDLE`, input `1` advances to `S1`; input `0` remains in `IDLE`.
- From `S1`, input `0` advances to `S2`; input `1` remains in `S1`, because the new `1` can start another candidate sequence.
- From `S2`, input `0` advances to `S3`; input `1` returns to `S1`, since the suffix `1` is a valid new prefix.
- From `S3`, input `1` advances to `S4`; input `0` returns to `IDLE`.
- From `S4`, input `0` advances to `S2`; input `1` advances to `S1`. This preserves overlap: the final `1` of the detected sequence is also treated as the first bit of a possible subsequent sequence.

Include a default transition to `IDLE` so an invalid or unknown state recovers safely.

Store the current state in an edge-triggered sequential block sensitive to both `posedge clk` and `negedge rst_n`. When `rst_n` is low, asynchronously set the state to `IDLE`. Otherwise, load the computed next state on each rising clock edge.

Generate `sequence_detected` as a Moore output based only on the current state. Set it high in `S4` and low in every other state, including during reset. Because the state changes to `S4` on the rising edge that consumes the final `1`, the output becomes high immediately after that edge. It remains high for one clock interval and normally becomes low after the next rising edge as the FSM leaves `S4`.

This timing produces outputs `0, 0, 0, 1` for input bits `1001`. With overlapping detection enabled, `1001001` produces `0, 0, 0, 1, 0, 0, 1`.
