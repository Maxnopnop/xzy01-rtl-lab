Implement `sequence_detector` as a five-state Moore FSM clocked on the rising edge of `clk`.

Use `reg` state storage and `localparam` encodings for `IDLE`, `S1`, `S2`, `S3`, and `S4`. A combinational next-state block should use a `case` statement with `if` decisions on `data_in`. Include a default branch returning to `IDLE` for recovery from an invalid state.

State meanings and transitions:

- `IDLE`: No useful prefix has been matched. If `data_in` is `1`, transition to `S1`; otherwise remain in `IDLE`.
- `S1`: The suffix `1` has been matched. If the next bit is `0`, transition to `S2`. If it is `1`, remain in `S1`, because that new `1` can begin another candidate sequence.
- `S2`: The suffix `10` has been matched. If the next bit is `0`, transition to `S3`. If it is `1`, return to `S1`, since the stream then ends with a possible starting `1`.
- `S3`: The suffix `100` has been matched. If the next bit is `1`, transition to `S4`, completing `1001`. If it is `0`, return to `IDLE`.
- `S4`: The full sequence `1001` has been matched. For overlapping detection, treat its final `1` as the first bit of another possible match. Therefore, transition to `S2` when the next bit is `0`, because the retained final `1` followed by `0` forms `10`; remain effectively at prefix `1` by transitioning to `S1` when the next bit is `1`.

Update the state in a sequential block sensitive to `posedge clk` and `negedge rst_n`. When `rst_n` is low, asynchronously set the state to `IDLE`. Otherwise, load the computed next state on each rising clock edge.

Implement `sequence_detected` as a Moore output derived only from the registered state: assert it when the current state is `S4`, and deassert it in every other state. Because the state enters `S4` at the rising edge that consumes the final `1`, the output becomes high immediately after that edge and remains high for one clock interval. On the following rising edge, the FSM leaves `S4` according to the next input bit, so the output normally returns low while retaining the appropriate overlapping prefix.

During asynchronous reset, the state becomes `IDLE`, which ensures `sequence_detected` is also low without waiting for a clock edge. This timing produces outputs `0,0,0,1` for input `1001` and permits repeated or overlapping matches.
